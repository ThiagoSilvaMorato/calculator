# Calculator — Project Guidelines

This is a full-stack calculator technical assignment.

- **Frontend:** React + TypeScript
- **Backend:** Go

## Principles

- Follow clean architecture principles without unnecessary abstraction.
- Prioritize clarity, maintainability, testability, and simple solutions.
- Do not add features or dependencies without a clear requirement.
- Do not overengineer the application.
- Keep frontend and backend responsibilities separated.
- Follow test-driven development when implementation begins.
- Before making architectural changes, explain the reason and request confirmation.

See `frontend/CLAUDE.md` and `backend/CLAUDE.md` for layer-specific guidelines.
